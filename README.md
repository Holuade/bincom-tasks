# bincom-tasks
A Python-based solution to Bincom’s recruitment task, featuring recursive search, Fibonacci sequence summation, binary-to-decimal conversion, and basic file parsing

This repository contains Python solutions to the recruitment task provided by Bincom. It includes basic algorithmic challenges and data manipulation using built-in Python tools.

## Contents

- `recursive-algo.py` - Recursive function to search for a number in a list.
- `random.py` - Generates a random 4-digit binary number and converts it to base 10.
- `fibonacci.py` - Calculates the sum of the first 50 Fibonacci numbers.
- `parser.py` - Parses voting data from a text file (if provided).
- `stats.py` - Basic statistical computations like mean, mode, and median from dataset.
- `db.py` - Database connection logic using MySQL (requires MySQL connector).

## How to Run

Ensure you have Python 3 installed, then:

```bash
python fibonacci.py
python random.py
python recursive-algo.py
